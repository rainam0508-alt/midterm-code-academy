# SkillSpring Academy

A simple and responsive Code Academy website created using HTML5 and CSS3.

## 1. Which HTML elements did you use?
I used header, nav, main, section, article, headings, paragraphs, links, and footer to organize the website content.

## 2. How did you arrange the course cards?
I used CSS Grid to arrange six course cards in three columns on desktop screens. Media queries adjust the layout for smaller screens.

## 3. Which CSS property was most useful?
CSS Grid was very useful because it helped me arrange the course cards neatly and made the layout easier to manage.

## 4. What problem did you face, and how did you solve it?
Making the website responsive was challenging. I used media queries to adjust the layout for tablet and mobile screens.

## 5. How did you make the website responsive?
I used CSS media queries for different screen sizes. On smaller screens, the course cards, About section, and Learning Journey change to fewer columns or a single column.

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
